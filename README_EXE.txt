========================================
  EASYINVOICE AUTO - HƯỚNG DẪN ĐƠN GIẢN
========================================

🎯 3 CHỨC NĂNG:
1. 📥 TẢI PDF - Tải hóa đơn về máy
2. 📝 TẠO HÓA ĐƠN - Tạo hóa đơn mới
3. 📧 GỬI EMAIL - Gửi hóa đơn qua email

========================================
  CÁCH SỬ DỤNG (CỰC ĐƠN GIẢN!)
========================================

🚀 BƯỚC 1: Mở ứng dụng
   → Double-click: EasyInvoiceAuto.exe

⏳ BƯỚC 2: Chờ cài đặt (CHỈ LẦN ĐẦU)
   → Lần đầu tiên sẽ tải Chromium (~100MB)
   → Mất 5-10 phút
   → Lần sau không cần nữa!

🌐 BƯỚC 3: Chrome tự động mở
   → Ứng dụng tự động mở Chrome
   → Nếu chưa đăng nhập EasyInvoice:
      • Popup hiện: "Vui lòng đăng nhập..."
      • Đăng nhập vào EasyInvoice trong Chrome
      • Click OK trong popup → Tiếp tục
   → Nếu đã đăng nhập rồi:
      • Popup hiện: "Bắt đầu xử lý ngay?"
      • Click Yes → Tự động chạy!

📂 BƯỚC 4: Chọn chức năng
   → Tab "📥 Tải PDF" - Tải hóa đơn
   → Tab "📝 Tạo hóa đơn" - Tạo mới
   → Tab "📧 Gửi email" - Gửi mail

📄 BƯỚC 5: Chọn file Excel
   → Click "📂 Chọn file"
   → Chọn file Excel của bạn

▶️ BƯỚC 6: Bắt đầu
   → Click "▶️ Bắt đầu..."
   → Ngồi uống cà phê ☕
   → Chờ hoàn thành!

💡 LƯU Ý:
   - Lần đầu đăng nhập → Popup yêu cầu xác nhận
   - Lần sau đã lưu → Popup hỏi "Bắt đầu ngay?"
   - Rất đơn giản, chỉ cần click OK/Yes!

========================================
  FILE EXCEL CẦN GÌ?
========================================

📥 TAB 1 - TẢI PDF:
   Sheet: "Summary"
   Cột cần có:
   - Tên công ty/nhà thuốc/quầy thuốc ✅
   - Mã số thuế ✅
   - Tổng tiền (không bắt buộc)

📝 TAB 2 - TẠO HÓA ĐƠN:
   Sheet: "Details"
   Cột cần có:
   - ID hóa đơn ✅
   - Mã số thuế ✅
   - Tên sản phẩm ✅
   - Giá đơn vị ✅
   - SL đặt ✅
   - vat ✅

📧 TAB 3 - GỬI EMAIL:
   Sheet: "Summary"
   Cột cần có:
   - Tên công ty/nhà thuốc/quầy thuốc ✅
   - Mã số thuế ✅
   - Địa chỉ gửi hóa đơn ✅
   - Tổng tiền (không bắt buộc)

========================================
  CẤU HÌNH EMAIL (CHỈ TAB 3)
========================================

Để gửi email, cần:
1. Email Gmail
2. App Password (KHÔNG phải mật khẩu Gmail!)

🔑 Cách tạo App Password:
1. Vào: myaccount.google.com
2. Bảo mật → Xác minh 2 bước
3. Mật khẩu ứng dụng → Tạo mới
4. Copy mật khẩu → Dán vào ứng dụng

========================================
  XỬ LÝ LỖI
========================================

❓ Lỗi: "Không tìm thấy Chrome"
   → Cài Chrome từ: google.com/chrome

❓ Lỗi: "Không tìm thấy hóa đơn"
   → Kiểm tra Mã số thuế trong Excel
   → Đảm bảo MST đúng format (TEXT)

❓ Lỗi: "Email không gửi được"
   → Kiểm tra Email và App Password
   → Đảm bảo dùng App Password, không phải mật khẩu Gmail

❓ Antivirus chặn
   → Thêm EasyInvoiceAuto.exe vào whitelist

❓ Chrome không mở
   → Đóng tất cả Chrome đang chạy
   → Chạy lại ứng dụng
