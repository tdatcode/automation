═══════════════════════════════════════════════════════════════
  BƯỚC 1: TEST TRƯỚC (QUAN TRỌNG!)
═══════════════════════════════════════════════════════════════

1. Mở Tab "📧 Gửi email"

2. Chọn file Excel

3. Điền Email + Mật khẩu

4. Click nút: 🧪 TEST - Gửi cho chính mình

5. Xác nhận popup

6. Chờ xử lý (Chrome tự động mở)

7. Kiểm tra hộp thư của BẠN (không phải khách hàng)

8. Mở email và kiểm tra:
   ✅ Thông tin khách hàng đúng?
   ✅ PDF đúng hóa đơn?
   ✅ Nội dung email OK?

✅ AN TOÀN HƠN

   - Đảm bảo nội dung đúng
   - Đảm bảo PDF đúng

✅ CHUYÊN NGHIỆP HƠN

═══════════════════════════════════════════════════════════════
  CÂU HỎI THƯỜNG GẶP
═══════════════════════════════════════════════════════════════

❓ TEST mode có gửi cho khách hàng không?
   → KHÔNG! Chỉ gửi cho email của BẠN

❓ TEST mode có tính phí không?
   → KHÔNG! Miễn phí như gửi email bình thường

❓ Có thể TEST nhiều lần không?
   → CÓ! Test bao nhiêu lần cũng được

❓ TEST xong có cần làm gì không?
   → Kiểm tra email → Nếu OK → Click THẬT

❓ Nếu TEST thấy sai thì sao?
   → Sửa file Excel → TEST lại → Đến khi OK mới THẬT

❓ Có thể dừng giữa chừng không?
   → CÓ! Click nút "Dừng lại"

═══════════════════════════════════════════════════════════════
  QUY TRÌNH KHUYẾN NGHỊ
═══════════════════════════════════════════════════════════════

1. Chuẩn bị file Excel

2. TEST với 1-2 dòng đầu tiên

3. Kiểm tra email TEST kỹ

4. Nếu OK → TEST toàn bộ file

5. Kiểm tra lại

6. Nếu OK → GỬI THẬT toàn bộ

7. Hoàn thành!
